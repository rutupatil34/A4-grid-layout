# 🧩 A4 Grid Layout

A modern and responsive frontend project built using **HTML** and **CSS Grid Layout** techniques.
This project focuses on creating structured layouts, responsive design patterns, and improving CSS grid skills through practical implementation.

---

## 📌 Features

* 🎨 Clean and modern UI
* ⚡ Organized webpage sections
* 🧩 CSS Grid implementation
* 💻 Beginner-friendly structure
* 🌐 Smooth and flexible design

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Grid
* Remix Icons

## ⚙️ Installation

Clone the repository:

```bash id="a4clone1"
git clone https://github.com/rutupatil34/A4-grid-layout.git
```

Open the project folder:

```bash id="a4cd1"
cd A4-grid-layout
```

Run the project by opening `index.html` in your browser.
